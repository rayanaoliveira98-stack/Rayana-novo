Formato de importação

JSON — mesmo formato dos packs:

{ "lang": "en", "concepts": { "apple": { "word": "apple", "art": "an apple", "pl": "apples",
  "adj": "a red apple", "act": "eat an apple", "sen": "I want an apple.",
  "q": "Where is the apple?", "a": "Here is the apple!", "syn": null, "var": null } } }

CSV — cabeçalho obrigatório (uma linha por conceito):

lang,concept,word,art,pl,adj,act,sen,q,a,syn
en,apple,apple,an apple,apples,a red apple,eat an apple,I want an apple.,Where is the apple?,Here is the apple!,

Os packs importados ficam em localStorage e são mesclados aos packs de fábrica ao abrir o aplicativo — sem rebuild.
