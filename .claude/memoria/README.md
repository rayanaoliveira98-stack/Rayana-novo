# Memória

Um arquivo por marca. Aqui fica o que foi aprendido e decidido, para não morrer no chat.

## Divisão de responsabilidade

| Onde | O que guarda | Quem atualiza |
|---|---|---|
| **Skills** (claude.ai) | fatos estáveis de marca: tom, ofertas, preços, CI | Rayana, pela claude.ai |
| **PLAYBOOK.md** | regras de operação e decisão | Claude, quando ela mandar |
| **memoria/** | o que foi aprendido, decidido e testado, com data | Claude, a cada sessão |

Regra: se um aprendizado virar regra fixa, ele **sobe** para a skill ou para o playbook e sai daqui.
A memória é o caderno, não o manual.

## Como alimentar

No fim de qualquer conversa que produziu decisão, resultado ou aprendizado:

> "grava na memória da STAFF24"

Claude escreve a entrada com data, o que foi decidido e por quê.

## Formato de cada entrada

```
## AAAA-MM-DD · título curto
**O quê:** a decisão ou o achado, em uma frase
**Por quê:** o raciocínio ou a evidência
**Consequência:** o que muda na prática
```

## Sobre chats na claude.ai

Claude Code não tem acesso ao histórico dos chats da claude.ai, e chat nenhum entra aqui sozinho.
Para agrupar conversas por marca na claude.ai, use **Projects**: um projeto por marca, com a skill
da marca anexada. Aí todo chat daquele projeto já nasce com o contexto certo.
O que precisa sobreviver ao chat continua vindo para cá, por pedido explícito.
