# Vorlagen

Alle Texte auf Deutsch, österreichisch, ohne Gedankenstriche. Platzhalter
in eckigen Klammern.

## Mahnung Stufe 1, freundliche Erinnerung

```
Betreff: Erinnerung zu Rechnung [Nummer]

Guten Tag [Name],

unsere Rechnung [Nummer] vom [Datum] über [Betrag] Euro ist seit
[Fälligkeitsdatum] offen. Wahrscheinlich ist sie im Alltag untergegangen.

Ich ersuche um Überweisung bis [neues Datum].

Falls die Rechnung bereits bezahlt wurde, betrachten Sie diese Nachricht
bitte als gegenstandslos.

Beste Grüße
Rayana Rose
Black Strategie
```

## Mahnung Stufe 2, verbindlich

```
Betreff: Zweite Zahlungserinnerung, Rechnung [Nummer]

Guten Tag [Name],

trotz unserer Erinnerung vom [Datum] ist die Rechnung [Nummer] über
[Betrag] Euro weiterhin offen.

Ich ersuche um Zahlung bis spätestens [Datum]. Nach diesem Termin behalte
ich mir weitere Schritte vor.

Für Rückfragen oder eine Ratenvereinbarung bin ich unter [Kontakt]
erreichbar.

Beste Grüße
Rayana Rose
Black Strategie
```

## Angebot, Grundstruktur

Nie als Preisliste bauen. Immer als Ergebnisversprechen.

```
1. Ausgangslage
   Was ich bei euch gesehen habe, in zwei bis drei Sätzen, konkret.

2. Ziel
   Was in [Zeitraum] erreicht sein soll, mit Zahl.

3. Weg
   Drei bis fünf Schritte, jeweils eine Zeile, keine Methodenvorträge.

4. Pakete
   Basis, Empfehlung, Ausbau. Die Empfehlung steht in der Mitte und ist
   optisch hervorgehoben.

5. Was ihr liefert
   Zugänge, Ansprechperson, Freigabezeiten.

6. Investition
   Betrag, Laufzeit, Zahlungsziel.

7. Risikoumkehr
   Was passiert, wenn das Ziel nicht erreicht wird.

8. Nächster Schritt
   Eine Handlung, eine Frist, ein Terminlink.
```

```
Maßnahme: [ein Satz]

```

## Freigabeanfrage an Rayana

```
Zur Freigabe: [Titel]
Agent: [Nummer und Name]
Was entschieden werden muss: [eine Frage, keine zwei]
Meine Empfehlung: [eine Option, mit Begründung in einem Satz]
Wenn keine Rückmeldung bis [Datum]: [was dann passiert]
```
