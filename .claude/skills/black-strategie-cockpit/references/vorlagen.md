# Vorlagen

Alle Texte auf Deutsch, österreichisch, ohne Gedankenstriche. Platzhalter
in eckigen Klammern.

## Mahnung Stufe 1, freundliche Erinnerung

```
Betreff: Erinnerung zu Rechnung [Nummer]

Guten Tag [Name],

unsere Rechnung [Nummer] vom [Datum] über [Betrag] Euro ist seit
[Fälligkeitsdatum] offen. Wahrscheinlich ist sie im Alltag untergegangen.

Ich ersuche um Überweisung bis [neues Datum].

Falls die Rechnung bereits bezahlt wurde, betrachten Sie diese Nachricht
bitte als gegenstandslos.

Beste Grüße
Rayana Rose
Black Strategie
```

## Mahnung Stufe 2, verbindlich

```
Betreff: Zweite Zahlungserinnerung, Rechnung [Nummer]

[Betrag] Euro weiterhin offen.

Ich ersuche um Zahlung bis spätestens [Datum]. Nach diesem Termin behalte
ich mir weitere Schritte vor.

Für Rückfragen oder eine Ratenvereinbarung bin ich unter [Kontakt]
erreichbar.

Beste Grüße
Rayana Rose
Black Strategie
```

## Angebot, Grundstruktur

Preise, Angebotstreppe und Verkaufsregeln kommen ausschließlich aus
`black-strategie-content`. Nie eine Preisvariante erfinden, nie ein Menü
anbieten. Pro Lead genau eine Empfehlung.

```
1. Ausgangslage
   Was ich gesehen habe, in zwei bis drei Sätzen, mit ihren eigenen
   Worten aus dem Erstgespräch, nie als Kritik.

2. Ziel
   Was in [Zeitraum] erreicht sein soll, mit Zahl.

3. Weg
   Drei bis fünf Schritte, je eine Zeile, keine Methodenvorträge.

4. Leistungen
   Was genau geliefert wird, bis wann.

5. Investition
   Ein Betrag, ein Zahlungsmodus, laut Angebotstreppe.

6. Risikoumkehr
   Was passiert, wenn das Ziel nicht erreicht wird.

7. Nächster Schritt
   Eine Handlung, eine Frist, ein Kanal.
```

Ablaufregeln, nicht verhandelbar:
- Die Präsentation wird im Termin gezeigt, nie per E-Mail verschickt.
- Danach geht nur die einseitige Versandfassung raus.
- Die ausgearbeitete Strategie kommt nach dem Auftrag, oder wird einzeln
  verkauft und angerechnet.

